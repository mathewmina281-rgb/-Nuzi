# NUZI × MATTHEW Exam Arena — الإصدار الجديد

واجهة عربية متجاوبة لامتحان الوحدة الأولى «دعوة الله لنا» للصف الثالث الإعدادي، مع بيانات الطالب، 30 سؤالًا، التصحيح، مراجعة الأخطاء، وشهادة عند الحصول على 21/30 على الأقل.

## محتويات الحزمة
- `index.html`: واجهة الموقع كاملة.
- `supabase-config.js`: إعدادات رابط Supabase والمفتاح العام وبيانات المشرف.
- `supabase-setup.sql`: إنشاء جداول النتائج والمشرف وسياسات الوصول.

## إعداد Supabase
1. افتح مشروع Supabase الموجود لديك، ثم SQL Editor > New query، والصق `supabase-setup.sql` وشغّله.
2. من Authentication > Users أنشئ مستخدمًا بإيميلك وكلمة مرور للمشرف.
3. في SQL Editor شغّل الأمر التالي بعد تغيير الإيميل:
   `insert into public.admin_users(email) values ('your-email@example.com') on conflict do nothing;`
4. من Project Settings > API انسخ Project URL و anon/public key، وضعهما في `supabase-config.js`. ضع إيميل المشرف في `ADMIN_EMAIL`.
5. انشر محتويات الحزمة في المستودع الجديد `-Exam` فقط، ثم فعّل GitHub Pages من Settings > Pages واختَر فرع `main` والمجلد `/ (root)`.
